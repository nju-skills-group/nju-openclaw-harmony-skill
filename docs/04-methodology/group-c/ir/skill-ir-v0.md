# SkillIR 规范草案（v0）

> 最终成果 C-3；状态：**待认领 / 结构提纲**。本文件是统一的规范草案入口；平台无关 IR 与目标绑定应共同设计、交叉复核，默认不拆成相互独立的交付包。阶段性设计讨论不等于完成验收；不要求实现完整 VM。

## 1. 目的与非目标

- 目标：根据 OpenClaw Skill 的描述、依赖、工具与乙组 L3 缺口，抽象可供移植分析/生成器消费的共同语义；单独描述鸿蒙侧绑定。
- 非目标：从零构造完整解释器/编译器；将鸿蒙 `module.json5`、`skillProfiles` 或 ArkTS 强制写入平台无关的核心表示；对未验证的运行时能力作保证。
