# C-2B：执行前预注册参数 v1

日期：2026-10-31。状态：**预注册草案，待 C-2A 与 C-2 成果协调人确认后冻结**。本次只固定参数，不含实验结果。

本文落实 [C-2A 方法说明](c-2a-method-v1.md)「运行前冻结的夹具」中明确交给 C-2B 的三项：**T_timeout、重试上限与计时容差**；未填写这些值不得执行超时类判定。本文的数值是丙组内部协议，不代表此前已获全组批准；甲组/乙组接口口径若有变化，按第 7 节追加变更记录，不静默改数。

## 1. 生效与变更规则

1. 参数在执行第一个用例**之前**冻结；冻结后只允许追加变更记录（说明原因、时间、影响哪些用例、旧值）。
2. 只对**已冻结参数**的用例出判定；缺参数的用例记「未测」，不临时估算。
3. 超时/重试参数属于**测试预算**，不是被测 Skill 的质量结论；某例超时只说明在该预算下未完成，不据此断言该 Skill 不可移植。
4. 同一用例在不同平台（OpenClaw / 鸿蒙）使用**同一套预算**；若目标端确实无法匹配，须在记录中单列差异及影响，不得只记录有利的一端。

## 2. 一次运行的定义与计时边界

| 指标 | 计时起点 | 计时终点 | 备注 |
| --- | --- | --- | --- |
| 端到端 | 提交用例输入（含初态复位完成） | 收到最终结果（最后一个回包/文件落盘） | 主指标，用于超时判定 |
| 工具执行 | 适配器收到参数 | 工具回包或抛错 | 与端到端分开记录，不混算 |
| 编译/AOT 成本 | 编译命令启动 | 产物落盘完成 | 只用于第 3 节工具链记录，不进入用例通过率 |
| 冷启动 | 清除会话/缓存后首次提交 | 收到最终结果 | 记录"清除了什么" |
| 热运行 | 冷启动后第 2 次起（第 1 次预热不计） | 收到最终结果 | 与冷启动分列，不合并统计 |

计时精度记录到 100ms；同时记录宿主本地时间与时区（本机为 Asia/Shanghai, UTC+08:00），避免用 UTC 与本地时间混算。

## 3. 通用重复、重试与容差

| 项目 | v1 取值 | 说明 |
| --- | --- | --- |
| 每用例每路径重复次数 | 3 次 | 继承 [用例协议](c-2a-cases-v1.md)「每路径 3 次」，每次复位初态 |
| 重试上限（网络/外部服务类） | 1 次 | 仅对连接失败、5xx、显式超时；401/403/404 与 schema 错误**不重试** |
| 重试上限（本地文件/本地 UI/会话类） | 0 次 | 本地失败即失败，重试会掩盖真实缺陷 |
| 重试上限（纯模型推理类 L1） | 0 次 | 模型抖动由 3 次重复体现，不叠加自动重试 |
| 超时判定容差 | T_timeout + 5s 或 +20%（取较大者） | 用于"是否有界失败"的判定，不用于放宽功能断言 |
| 计时比较容差 | ±20% 且 ≥ ±100ms | 仅用于冷/热对照与端到端对比，不用于通过/失败 |
| 单例总预算（含重试） | 300s | 超出即记「失败（超出预算）」，不事后追加预算 |
| 重试与重复的关系 | 不同概念 | 3 次是**独立运行**；重试是**同一次运行内**的重发，重试必须计入该次记录 |

判定纪律：
- 3 次独立运行**全部**满足必需断言才计该例通过；任一次失败则该例记「失败」或「部分通过」（部分场景未跑完）。
- 发生重试的运行须标注重试次数与原因，不得把"第 2 次成功"直接写成通过而不留痕。
- 故障注入用例的**正常分支**与**故障分支**分别计数，不合并成单一通过率。

## 6. 工具链验证的预注册判据

C-2B 的"工具链验证"允许四种状态，判据如下（与 [C-2A 第 3 节](c-2a-method-v1.md)一致，此处给出 C-2B 的最小证据集）：

| 状态 | 判据 | 最小证据 |
| --- | --- | --- |
| 通过 | 真实调用工具处理固定输入，产出可检查的适配产物，且执行前声明的检查项全部完成 | 工具与版本、固定输入哈希、完整命令、目标适配器/目标平台、产物路径与哈希、检查项逐条结论 |
| 部分通过 | 工具可运行并完成部分阶段，但声明的检查项有关键项未完成（如仅生成计划未产出适配物） | 上述全部 + 未完成项及其原因 |
| 失败 | 工具运行但报错，或产物不满足声明的检查项 | 完整报错文本、退出码、复现命令 |
| 阻断 | 工具在本环境无法运行（平台不受支持、缺密钥、缺宿主） | 阻断点、报错原文、可行的替代路径 |

执行前声明的"检查项"限定为该工具**真实支持**的能力，不按论文声称的功能预设。工具链验证结论不推导目标运行结论：即使某工具成功产出适配物，未在鸿蒙上实际调用仍记"目标运行：未测"。
