### 一个**不建议**擅自做的选项

有一个看似能绕开凭证的办法：给 OpenClaw 配一个桩模型（OpenAI 兼容端点的假响应），跑 `openclaw agent --local`，拿到"技能被选派、脚本被调用"的链路证据。技术上可行，但：

- 模型决策是**我们写的**，产物不是 Skill 的行为，只能证明管道通，不能记作原平台基线；
- 预注册没冻结这种运行形态，做了也只能进"工具链"栏，不能进"原平台调用"栏；
- 一旦写进报告，极易被读成"已经跑通了"。

若组内认为需要这条链路证据，请先由 C-2A 在预注册追加一条运行形态（例如"桩模型运行：仅证明选派与调用链，不计入行为断言"），再动手。丙组不单方面引入。
