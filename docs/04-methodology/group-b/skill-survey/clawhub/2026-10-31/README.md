# S2 ClawHub Skill 普查 v0.1 — 交付说明

## 核心交付物

- `ClawHub-Skill-Survey-v0.1.xlsx`：主工作簿，包含摘要、24项普查表、5项重点复核、修改记录与范围说明。
- `ClawHub-Skill-Survey-v0.1.csv`：24项普查表的通用交换版本。
- `focus-review.md`：5项重点样本的证据化复核记录。
- `changes.csv`：重点复核产生的修改与争议记录。
- `scope-and-limitations.md`：样本边界、方法和未验证事项。

## 核验结果

- 固定版本样本：24项。
- 选样类别：8类，每类3项。
- 已校验固定版本源文件：518个。
- 重点复核：5项，其中4项“本次已复核”、1项“存在争议”。
- 静态候选分类：L1 3项、L2 5项、L3 16项。

## 使用顺序

1. 先打开 Excel 工作簿的“摘要”页了解总体结论。
2. 在“普查表”页筛选类别、分类或复核状态。
3. 对黄色重点样本查看“重点复核”页；红色项表示存在争议。
4. 继续做运行验证时，将结果回填至“原平台状态”和“鸿蒙状态”。

## 重要边界

本交付物是固定版本源码的静态普查。调查过程未安装、未执行被调查 Skill，也未完成 OpenClaw 原平台或鸿蒙端运行验证。五项重点样本按依赖证据复杂度和分类边界选择；追加新的重点样本时，应保留本次记录。
