**`timeout` 的含义**（引自该页 `urllib.request.urlopen(url, data=None, [timeout, ]*, context=None)` 的说明）：

> “The optional *timeout* parameter specifies a timeout in seconds for blocking operations like the connection attempt (if not specified, the global default timeout setting will be used). This actually only works for HTTP, HTTPS and FTP connections.”

也就是说，`timeout` 以秒为单位，规定连接尝试等阻塞操作最多等待多久；如果省略该参数，就使用全局默认超时；该设置在 HTTP、HTTPS、FTP 连接上有效。同页的 `OpenerDirector.open` 说明也表达了相同意思，并补充说明：这个超时是指每次套接字操作的超时，并不会限制整个下载总时长。
